# RFP 合规预审报告（示例）

## 审查范围
- 已处理文件：`某政企项目招标文件.pdf`、`产品白皮书.txt`、`营业执照与ISO证书.pdf`
- 未处理/受限文件：`投标文件最终版.ofd`，P0 工具暂不支持 OFD，需要用户提供 PDF/DOCX 导出版
- 是否包含企业证据比对：是，已比对产品白皮书和部分资质材料
- 主要限制：未提供报价表、投标保证金凭证、签章页和偏离表模板，因此价格、保证金、签章和模板填报只能做风险提示，不能做最终满足判断
- 说明：本报告为 Agent 预审结果，不能替代法务、投标负责人或评审机构的最终确认

## 文件缺失与限制
- P1：缺少报价表/分项报价/保证金凭证；影响：最高限价检查、报价风险检查、保证金检查；建议：如需检查报价、最高限价或保证金，请补充报价表或保证金凭证。
- P2：缺少招标方偏离表模板；影响：按模板填报偏离表；建议：如需按招标方格式生成偏离表，请补充 Excel/Word 偏离表模板。
- P2：缺少我方投标/应标文件草稿；影响：已写响应内容审查、签章/授权/格式检查；建议：如需审查已写投标文件，请补充我方投标/应标文件草稿。

### 不支持文件
- `投标文件最终版.ofd`：unsupported extension: .ofd

### 建议追问用户
- 是否可以提供 `投标文件最终版.ofd` 的 PDF 或 DOCX 导出版？
- 是否已有招标方指定的 Excel 偏离表模板？
- 是否需要我先只输出风险清单，还是等待报价表后再判断价格风险？

## 高危风险
- 风险：P0 致命风险 / 未发现证明材料
  来源：`某政企项目招标文件.pdf` 第 12 页，投标人须知前附表
  条款：投标文件必须按招标文件要求签署、盖章，法定代表人或授权代表须签字或盖章。
  当前证据：当前材料中未发现投标函、授权委托书、签章页或电子签章验证材料。
  判定：疑似形式审查高危风险，不能判断满足。
  建议：补充投标函、法定代表人授权委托书、签章页或电子签章验证材料，并由投标负责人确认签署主体与项目编号一致。

- 风险：P0 致命风险 / 未发现证明材料
  来源：`某政企项目招标文件.pdf` 第 18 页，商务要求
  条款：投标报价不得超过最高限价 1,000,000 元。
  当前证据：未提供报价表或分项报价。
  判定：无法判断是否超限，属于价格审查阻断项。
  建议：补充报价表、分项报价和税率说明；若报价接近最高限价，建议人工复核大小写金额、包号和税率口径。

## 补料清单
| 事项 | 负责人建议 | 原因 | 优先级 |
| --- | --- | --- | --- |
| 投标函签字盖章页 | 投标专员/法务 | 形式审查核心材料缺失 | P0 |
| 法定代表人授权委托书 | 投标专员/法务 | 授权范围和签署主体需证明 | P0 |
| 报价表和分项报价 | 财务/商务 | 无法判断是否超过最高限价 | P0 |
| 双活容灾架构图 | 产品/解决方案 | 星号技术项仅有产品能力证据，缺项目化响应 | P1 |
| 售后 2 小时响应承诺 | 交付/售后 | 商务响应证据不足 | P1 |
| 招标方偏离表模板 | 投标专员 | 需要按模板导出偏离表 | P2 |

## 应标建议
- 对于 `REQ-0001`，可基于现有证据生成待确认话术：
  “我方系统支持同城双活部署，具备容灾切换能力。针对本项目，我方建议采用主备/双活部署架构，并在实施方案中补充双活容灾架构图、切换流程和演练机制。该响应需以最终技术方案和报价范围确认为准。”
- 对于 `REQ-0004`，可基于现有证书生成待确认话术：
  “我方具备 ISO27001 信息安全管理体系认证，证书处于有效期内。投标文件将附证书复印件并加盖公章，具体认证范围以证书载明内容为准。”

## 待人工确认
- `REQ-0001`：星号技术项虽有产品白皮书证据，但需确认本项目交付范围是否包含双活部署。
- `REQ-0002`：签章与授权材料未提供，需投标专员和法务确认。
- `REQ-0003`：报价材料未提供，需商务/财务确认。
- `REQ-0004`：ISO27001 证书主体、有效期、认证范围需人工复核。
- `REQ-0005`：售后 2 小时响应承诺缺失，需交付负责人确认是否可承诺。

## WebSearch 使用说明
- 本示例未使用 WebSearch 判断企业自身能力。
- 若需要核对财政部 87 号令、《招标投标法实施条例》或电子招投标规则，Agent 可使用 WebSearch 检索官方来源，并在报告中附 URL 和引用片段。
- WebSearch 只能补充公共法规和公开标准，不能替代用户提供的企业资质、报价、产品能力或签章材料。
